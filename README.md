# busqueda_leads

Repositorio de plantillas y demos generadas para el flujo de detección de leads.

## Estructura
- `demo-kiosco.html`, `demo-veterinaria.html`, `demo-restaurante.html`, `demo-inmobiliaria.html`
  → plantillas maestras, no se editan directamente.
- `demo/` → acá se suben las demos ya personalizadas por lead (ej. `demo/veterinaria-sanmartin.html`).

## Activar GitHub Pages
Settings → Pages → Branch: main, carpeta /root → Save.
La URL pública queda: https://sabarettaGH.github.io/busqueda_leads/
